Tanque Studio · Design Exploration

5 alternative layouts

Five distinct navigation and layout paradigms for Tanque Studio — each preserves every existing capability (prompt, model/sampler, parameters, LoRAs, img2img, moodboard, gallery, metadata/assist/actions, DT Project Browser, Labs, Settings) while breaking from the generic "left sidebar + split panels" template. All are interactive — click through each one.

Every concept replaces plain dropdown/list controls with visual card pickers (models, LoRAs, quick-starts) and adds visible feedback for actions — progress fills, glows, toasts — addressing the two biggest complaints with the current UI. Typography (IBM Plex Mono + Atkinson Hyperlegible) stays constant across all five as the one fixed brand thread; everything else — chrome, density, materials, even color — is fair game and varies concept to concept.
01
Canvas-first · Floating
Command Deck
No permanent chrome at all. The canvas fills the window; a floating glass prompt bar docks at the bottom, a slim icon rail summons panels on demand, and ⌘K opens a full command palette for navigation and actions.
